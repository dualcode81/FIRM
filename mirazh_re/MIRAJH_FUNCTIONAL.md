# Мираж-GSM: полный разбор прошивок (M8-03 v1.14 + A8-03 v1.3)

Полная декомпиляция выполнена: дизассемблирование всего образа + C-псевдокод каждой функции.
- `m8_decompiled.c` — 1,73 МБ, все функции M8-03 на C
- `a8_decompiled.c` — 2,15 МБ, все функции A8-03 на C
- `m8_full_dis.txt` / `a8_full_dis.txt` — полные листинги с аннотацией строк и пулов
- Функции: M8 — 1810 (по прологам) / 7244 (в C-выходе), A8 — 1950 / в C 2 МБ
- Базы: флеш 0x00100000 (в листингах VA = файл+0x100000), RAM 0x00200000 (SAM7S256)

## 1. Тract исходящих SMS (M8) — куда смотреть в первую очередь

Событие → очередь TLV-записей → модем:

1. **Запись типа 0x61 ('a') = SMS** — обработчик `f0x11442C` (декомпилирован):
   - вызовы `f0x104BF4(3,...,"MGS=")` / `f0x104C84(3,...,"MGS=")` — форматирование `AT+CMGS=<len>` (движок модема дописывает `AT+C`)
   - `f0x114C34` → пуш в канал (g5-очередь) → консьюмер отправляет PDU
2. **Отправитель MSRV-уведомления** `f0x12E5A8`:
   - `f0x11D71C(0x20E930)` — сессионный ключ; `f0x113498(0x20EED0)` — адресата
   - `f0x125580(a3,a4)` — тело: 8 байт записи + XOR-контроль
   - `f0x1258DC(ver=17, ...)` — **пакет-билдер MSRV**: `'MSRV' + len=body+19 + ver + typ + ENC_KEY1(dest,src,hcrc)`; при ver≠18 тело шифруется `f0x1255D0`
3. **SKey-кодер** `f0x1255D0` (кодировщик) / `f0x125614` (декодер) — совпал байт-в-байт с PC-реализацией:
   `k' = (k<<8)|b`, поток `b = k>>20 ^ k>>23 ^ c`, подстановки 0→0x80, 0xFF→0x7F
4. **CRC16-XMODEM**: `f0x11694C` (расчёт), обёртки `f0x1168B0` (байт), `f0x1168F4` (u16, режим store/verify)
5. Каналы-обёртки уведомлений: `f0x12D788`, `f0x12E180`, `f0x13239C` (getter'ы типа канала; SMS-канал=6)

**Точка патча «SMS текстом»:** в `f0x12E5A8` заменить сборку MSRV-тела
(`f0x125580`+`f0x1258DC`) на сборку PDU с UCS-2 текстом, взятым из RU-словаря
прошивки (строки `Пожар 1/2`, `Охр тревога`, `Снят`, `Саботаж`... в области
файл 0x39000–0x39C00 = VA 0x139000+). Движок `MGS=` переиспользуется как есть.

## 2. Приёмные команды (M8) — уже работают по SMS/GSM
- Запись **0x60 ('`')** — обработчик `f0x114224`: 5-байтный адрес + битовая маска,
  цикл `f0x115344(выход, бит)` = **управление реле/шлейфами из входящей записи**.
- Входящие SMS: парсер PDU-префиксов `0004AA`/`0008AA`, `AT+CMGF=0`, `AT+CMGL=4`.
- TLV-разметчик `f0x141E0`: тип = байт & 0x7F; бит7 → ветка 0x60, иначе 0x61.

## 3. Командные заголовки ПЦН/Стрелец (M8)
`f0x11BA9C` — switch по коду команды (35,42,48–57,97–102) → пара заголовочных
слов (0xBD..., +дельты 128/268/536/692/780/936); используется радио-трансляцией
('Strelec', 'Transit' в пулах). Не трогать при патче SMS.

## 4. A8-03 — эталон человекочитаемых сообщений
- **Шаблонизатор текста**: область `f0x143990+` (VA 0x143xxx), форматы
  `"...через %u (мин): "`, `"Переход на %u-ю сеть..."` — sprintf по RU-шаблонам
  (область строк файл 0x42800–0x44700).
- A8 тоже в PDU-режиме (`AT+CMGF=0`), но тело — UCS-2 текст из шаблонов.
- A8 имеет 143 .wav и словарь событий; M8 — тот же словарь слов, но бинарное тело.
- Общий код: MSRV/SKey/CRC/PDU-шаблон `0011000B91` идентичны — переносим.

## 5. Диспетчерские таблицы (массивы указателей в данных)
M8 (адрес VA, число энтов): 0x137F58(13), 0x1380A8(12), 0x1380EC(12),
0x137F0C(10), 0x1384A0(9) + ещё 8 таблиц по 8 — обработчики команд/каналов;
цели размечены строками в `m8_tables.json`/`m8_master.md`.
A8 — в `a8_tables.json`.

## 6. Ключи протокола (подтверждены в машинном коде)
- `'MSRV'`-шаблон билдера: VA 0x13D488 (M8)
- SKey: внешний KEY1=1403142540 (PC), сесс. ключ = `[0x20E930+4]` getter `f0x11D71C`
- CRC16-XMODEM: поли 0x1021, init 0 (known-answer «123456789»=0x31C3)
- Sbin-обёртка прошивки: LFSR-XOR + CRC16, подпись отсутствует → пересборка
  пропатченного образа возможна (тест флешки не делался!)

## 7. План патча (что менять, конкретно)
1. В `f0x12E5A8` (файл 0x2E5A8): вместо вызова билдера MSRV (`f0x1258DC`) —
   новый код: взять код события из a3/a4, по таблице выбрать RU-фразу,
   сконвертировать cp1251→UCS2, собрать PDU (шаблон `0011000B91` + длина UCS2),
   отдать в тот же `f0x121714`/канал.
2. Место под новый код: нулевых окон нет → карвать из ветки ПЦН-атрибутов или
   из хвоста 0x3BF00 (резервная страница). Размер добавок ~300–400 байт.
3. Пересобрать .sbin (sbin_enc по обратному алгоритму SLibX), CRC16 посчитается
   автоматически. Откат — родной .sbin + SAM-BA при кирпиче.
