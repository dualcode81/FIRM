# FIRM

Резервная копия ConfiguratorPro (НПП «Стелс») + артефакты реверса Мираж-GSM-M8-03.

- корень — папка ConfiguratorPro: конфигуратор, драйверы USB-адаптера, прошивки .sbin, providers/updates
- devices/ — конфигурация прибора S/N 1243379 (пароль связи — заводской 11111)
- log/ — пресеты журнала конфигуратора
- mirazh_re/ — результаты реверса: расшифрованные прошивки (в т.ч. m8-03_1_14_ORIGINAL_BACKUP.sbin — откатная), полная декомпиляция (.c, листинги, fmap/tables), утилиты sbin_dec.py, sam_flash.py, генераторы патчей

ВНИМАНИЕ: m8-03_1.14_textsms_v1.1.sbin — повреждённая патч-прошивка, НЕ заливать на прибор.
